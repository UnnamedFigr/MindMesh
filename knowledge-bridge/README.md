# knowledge-bridge

A portable CLI tool that uses Gemini's long-context API to extract best practices, anti-patterns, and targeted instruction-file improvements from a set of source documents (PDFs, text files, research notes, engineering docs).

Think of it as a programmable NotebookLM: you drop in your sources, and the tool extracts structured, actionable knowledge that can be synced back into your repo's agent instructions.

---

## Prerequisites

- Python 3.11+
- A Gemini API key — get one free at [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
- Source documents in `sources/` (PDFs, `.txt`, `.md`, `.html`)

---

## Setup

```bash
# From the knowledge-bridge/ directory
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS/Linux

pip install -r requirements.txt

# Set your API key
set GEMINI_API_KEY=your_key_here   # Windows
# export GEMINI_API_KEY=your_key_here  # macOS/Linux
```

## Quick Start

```bash
# 1. Drop source files into sources/
#    (PDFs, text files, markdown, engineering docs)

# 2. Upload sources and create a context cache
python bridge.py ingest

# 3. Extract best practices (all layers)
python bridge.py extract best-practices

# 4. Extract best practices for a specific layer
python bridge.py extract best-practices --layer backend

# 5. Extract anti-patterns
python bridge.py extract anti-patterns

# 6. Ask a grounded question
python bridge.py clarify "When should we use context caching vs. a full prompt?"

# 7. Propose improvements to an existing instruction file
python bridge.py refine ../.github/instructions/backend-python.instructions.md

# 8. Preview what sync would write
python bridge.py sync

# 9. Apply the sync (writes into repo files using marker blocks)
python bridge.py sync --apply

# 10. Check cache status and available outputs
python bridge.py status
```

## Commands

| Command | Description |
|---|---|
| `ingest` | Upload `sources/` to Gemini Files API, create a context cache |
| `extract best-practices [--layer]` | Extract rules from cached sources into `outputs/best_practices.json` |
| `extract anti-patterns` | Extract anti-patterns into `outputs/anti_patterns.json` |
| `clarify "question"` | Ask a grounded follow-up, save answer to `outputs/clarification_*.json` |
| `refine <file>` | Propose surgical improvements to an instruction file |
| `sync [--apply]` | Write outputs into repo files (dry-run by default) |
| `status` | Show cache info and available outputs |

---

## How sync works

The `sync` command reads `sync_targets` from `bridge.config.json` and injects extracted content into the target files using idempotent marker blocks:

```markdown
<!-- knowledge-bridge:start -->
## Best Practices _(auto-generated by knowledge-bridge)_

- **[Error Handling]** Always wrap external calls in try/except with specific exception types.
  > Generic except clauses hide bugs and make debugging harder.

<!-- knowledge-bridge:end -->
```

Re-running `sync --apply` replaces the block in place — it never duplicates content.

## Migrating to another project

The only file that changes between projects is `bridge.config.json`.

### Step 1 — Copy the tool

```
your-new-project/
  knowledge-bridge/           ← copy this entire directory
    bridge.py
    config.py
    schemas.py
    requirements.txt
    bridge.config.json        ← edit this
    prompts/                  ← keep as-is (generic)
    sources/                  ← add your new sources
    .gitignore
```

Exclude from copy (already gitignored): `cache/`, `outputs/`, `.venv/`

### Step 2 — Edit bridge.config.json

```json
{
  "project_name": "YourProjectName",
  "tech_stack": "Python 3.12 / Django / React 18 / PostgreSQL",
  "model": "gemini-2.5-flash",
  "cache_ttl_seconds": 3600,
  "sources_dir": "./sources",
  "outputs_dir": "./outputs",
  "cache_dir": "./cache",
  "sync_targets": [
    {
      "extraction_type": "best_practices",
      "filter": {"applicable_to": ["backend"]},
      "target_file": "../.github/instructions/backend.instructions.md",
      "section": "Extracted Best Practices"
    },
    {
      "extraction_type": "anti_patterns",
      "filter": {},
      "target_file": "../.github/error-patterns.md",
      "section": "Anti-Patterns"
    }
  ]
}
```

**Config fields:**

| Field | Description |
|---|---|
| `project_name` | Used in prompts to give context |
| `tech_stack` | Used in prompts; describe your stack concisely |
| `model` | Gemini model name (see model options below) |
| `cache_ttl_seconds` | How long the file cache lives (max 3600 = 1 hour) |
| `sync_targets` | List of output → file mappings for `sync` |
| `sync_targets[].extraction_type` | `best_practices` or `anti_patterns` (matches output filename) |
| `sync_targets[].filter` | Dict of field:value to filter items (e.g. layer filter) |
| `sync_targets[].target_file` | Relative path from `knowledge-bridge/` to the target repo file |
| `sync_targets[].section` | Heading used for the generated block |

### Step 3 — Install and run

```bash
cd knowledge-bridge
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
# Set GEMINI_API_KEY
python bridge.py ingest
python bridge.py extract best-practices
python bridge.py sync --apply
```

## Model options

| Model | Speed | Cost | Notes |
|---|---|---|---|
| `gemini-2.5-flash` | Fast | Low | Default — good balance |
| `gemini-2.5-pro` | Slower | Medium | Better for complex refine tasks |
| `gemini-3-flash-preview` | Fast | Low | Newer, check availability |

Change the `model` field in `bridge.config.json` to switch.

---

## Cost guide

Context caching means the source documents are charged once per cache creation, not per query. With caching:

- A typical ingest (5–10 PDFs, ~500 pages total): ~$0.02–0.05
- Each `extract` or `clarify` call against the cache: ~$0.001–0.005
- A full session (ingest + 3 extractions + 5 clarifications): under $0.15

Without caching, each call re-sends all source content — roughly 10× more expensive.

  schemas.py            ← Pydantic response models

## Troubleshooting

**`No cache found`** — Run `python bridge.py ingest` first. Caches expire after `cache_ttl_seconds` (default 1 hour).

**`GEMINI_API_KEY not set`** — Set the env var before running. Free tier available at aistudio.google.com.

**`minimum input token count`** — Context caching requires at least 1,024 tokens in sources. Add more source content.

**`FileState.FAILED`** — The file couldn't be processed. Check that the file isn't corrupted and is under 50 MB.
